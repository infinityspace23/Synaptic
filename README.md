# __*Synaptic*__
## A collation of all codework related to the visualization tool, Synaptic
It was after having ran past 8 weeks of CS50x that I wanted to explore other domains of Computer Science. Machine learning albeit a complex and out-of-reach domain, I worked my way through what I could understand with the help of the Internet and LLMs(ironically). The process of learning about ANNs made me think deeper about knowledge and how much more effort is used to store it, than really talked about since we as humans do it naturally. This codebase is a collation of the code that either I have written (at times with the help of an AI tutor, at no point was anything taken wholesale) or learnt of from kind strangers on the Internet. 

## Specifications
A couple of models were used for comparisons, namely ResNet, all-minilm-l6-v2, and FashionCNN(self trained, only 5 epochs). 
I'll admit the code for RSA.py has poor optimisation and I really only found out when it took really long to run maybe 30% of the analysis. To remedy it, I did use AI to optimize my code for Google Colab's CUDA limits (~12GB memory). The heatmaps produced were only possible with Colab's compute assistance.

No weights have been uploaded, if you're interested in them do contact me at the blog linked below!

## Endings
This is ultimately my first work (of course as a beginner) so do reach out to me for any improvements!
